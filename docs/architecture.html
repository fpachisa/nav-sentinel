NAV Sentinel

A governed fleet of fund-accounting agents that clears reconciliation exceptions inside the NAV production window — and the control plane that makes deploying it defensible.

Figure 1

The system

Agents above, data below, and exactly one crossing. The gateway is drawn as a band rather than a box because no call reaches data without passing through it — that is the architecture's central claim, and a box on the side would misstate it.

Figure 2

What happens to a tool call

An agent cannot hand the gateway a function to run — it emits a name and arguments, which is all a language model can produce anyway. Resolution happens inside the boundary, against a frozen catalogue.

Figure 3

The quarantine boundary

Issuer filings are written by someone else and land in a model's context, which makes them the fleet's real attack surface. Screening alone turned out not to hold, so the boundary is structural.

Why screening alone was not enough

Measured against the live service with the injection held constant at 1,008 bytes. Placement decides the outcome, not concentration:

Above a threshold between 40,827 and 41,329 bytes the filter reports execution_state: EXECUTION_SKIPPED and invocation_result: PARTIAL while filter_match_state still reads NO_MATCH_FOUND — so code checking only the match state cannot distinguish a skipped scan from a clean one. Windowing at 1 KB with 500 B overlap catches the injection at every position tested, with no false positives; 4 KB windows do not. All three response fields are now checked, and an unscreenable value is refused rather than passed through.

Figure 4

Definition of done is arithmetic

A NAV difference is not another break to investigate. It is the control total, and every break is a candidate explanation for it. The cycle closes only when the fleet's own proposed corrections account for the whole difference.

Model and location

gemini-3.7-flash for investigation, gemini-3.5-flash-lite for triage. Both are served only from the global location — every 3.x identifier returns 404 in us-central1, where nothing newer than the 2.5 family resolves. Model Armor is the mirror: regional endpoint only.

Deterministic by design

Break detection, materiality and approval routing contain no model calls. Whether two numbers differ, and who may clear a difference of a given size, must be reproducible and testable. Models are reserved for explaining why.

Enforcement outside the agent

An agent that checks its own permissions is one prompt away from deciding it has them. Every decision is made by the gateway from the published manifest, and recorded on the case trace.
